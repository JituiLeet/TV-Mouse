# 电视鼠标

[简体中文](./README.md)　|　[English](./README.en.md)

在 Android TV 上用遥控器控制鼠标指针，在其他应用中也能像鼠标一样操作。

## 功能

- 悬浮鼠标指针：方向键移动，确定键单击，按住确定键执行长按。
- 固定滑动：按音量减键 + 菜单键开启；开启后可控制界面滑动，只有长按返回键 3 秒才能关闭。
- 快捷打开设置：按音量加键 + 菜单键。
- 自定义指针外观：导入 128 × 128 像素的 PNG 或 JPG 图片，可设为鼠标指针、修改名称或删除；普通模式与固定滑动模式可共用外观。
- 中英文界面：默认跟随系统语言，也可手动切换。

## 使用

打开应用主界面，授予悬浮窗权限与无障碍服务权限后，即可开启鼠标功能。使用遥控器方向键移动指针，按确定键单击，按住确定键执行长按。

按音量加键 + 菜单键打开设置。按音量减键 + 菜单键开启固定滑动；固定滑动开启后，按音量减键 + 菜单键不会将其关闭，需长按返回键 3 秒关闭。正常模式下返回键保持系统原有行为。

## 自定义外观

在设置中的“自定义外观”选项中，导入 `128 × 128` 像素的 PNG 或 JPG 图片，推荐使用透明背景 PNG。选择自定义外观后，可以将其设为鼠标指针、修改名称或删除。普通鼠标模式与固定滑动模式可共用同一外观。
