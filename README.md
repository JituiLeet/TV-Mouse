# 电视鼠标

[简体中文](./README.md)　|　[English](./README.en.md)

在 Android TV 上用遥控器控制鼠标指针，在其他应用中也能像鼠标一样操作。

## 功能

- 悬浮鼠标指针：方向键移动，确定键单击，按住确定键执行长按。
- 鼠标灵敏度与指针大小：可在“更多设置”中调整。
- 精简主界面：主界面仅提供开启/关闭鼠标指针、隐藏/显示鼠标指针和“更多设置”入口。
- 固定滑动：按音量减键 + 菜单键开启；开启后只有长按返回键 3 秒才能关闭。
- 快捷键设置：可为打开设置、开启固定滑动、隐藏/显示指针配置组合按键，或配置长按单个按键及触发时长；默认打开设置为音量加 + 菜单键，开启固定滑动为音量减 + 菜单键。
- 自定义指针外观：导入 128 × 128 像素的 PNG 或 JPG 图片，可设为鼠标指针、修改名称或删除；普通模式与固定滑动模式可共用外观。
- 中英文界面：默认跟随系统语言，也可手动切换。

## 使用

开启鼠标前，请授予悬浮窗与无障碍服务权限。主界面提供鼠标开启/关闭、指针隐藏/显示与“更多设置”三个入口。进入“更多设置”可调整灵敏度、指针大小、外观、语言及相关权限。

默认按音量加键 + 菜单键打开设置，按音量减键 + 菜单键开启固定滑动；固定滑动开启后，需长按返回键 3 秒关闭。快捷键可在“更多设置”→“快捷键设置”中自定义。无障碍服务中断或发生异常时，应用会尝试关闭按键过滤，降低遥控器按键被持续拦截的风险。


## 兼容性

支持 Android 4.4（API 19）至 Android 15（API 35）。
