# 电视鼠标

[简体中文](./README.md)　|　[English](./README.en.md)

在 Android TV 上用遥控器控制鼠标指针，在其他应用中也能像鼠标一样操作。

## 功能

- 悬浮鼠标指针：方向键移动，确定键单击，长按确定键长按。
- 在设置中开启“滑动界面操作”后，可控制界面滑动。
- 支持自定义指针观：内置默认外观，也可导入图片并保存为新外观。
- 支持中英文界面：默认跟随系统语言，也可手动切换。

## 使用

打开应用主界面，授予悬浮窗权限与无障碍服务权限后，即可开启鼠标功能。

开启后，使用遥控器方向键移动指针，按确定键进行点击，长按确定键执行长按操作。

长按返回键 3 秒可打开设置，也可以在应用主界中直接进入自定义外观或语言设置。

l在设置中开启“滑动界面操作”后，可控制界面滑动。在开启后长按返回键 3 秒或者在设置中即可关闭。

在应用主界面或设置中，可以隐藏或关闭鼠标指针。设置语言及自定义外观。

## 自定义外观

在设置中的“自定义外观”选项中，导入 `128 × 128` 像素的 PNG 或 JPG 图片，推荐使用透明背景 PNG。

输入名称并保存后，即可在外观列表中切换使用。

## 兼容性

支持 Android 4.4（API 19）至 Android 14（API 34）
