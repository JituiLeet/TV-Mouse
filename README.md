# 电视鼠标

[简体中文](./README.md)　|　[English](./README.en.md)

在 Android TV 上用遥控器控制鼠标指针，在其他应用中也能像鼠标一样操作。

## 功能

- 悬浮鼠标指针：方向键移动，确定键单击，按住确定键执行长按。
- 鼠标灵敏度与指针大小：可在“其他设置”中调整。
- 主界面：开启/关闭鼠标指针、隐藏/显示鼠标指针、打开悬浮窗权限、打开无障碍设置、其他设置和说明。
- 快捷键自定义：在“其他设置 → 快捷键设置”中配置打开设置、开启固定滑动、隐藏/显示指针和关闭固定滑动的快捷键。
- 按键组合：可设置一个或多个按钮，最多三个；按下组合中的按钮触发对应功能。
- 长按快捷键：可选择任意一个遥控器按钮并设置长按时长，最低 1000ms，不设上限。
- 固定滑动：默认按音量减键 + 菜单键开启，默认长按返回键 3 秒关闭；可在快捷键设置中调整。
- 自定义指针外观：导入 128 × 128 像素的 PNG 或 JPG 图片，可设为鼠标指针、修改名称或删除；普通模式与固定滑动模式可共用外观。
- 中英文界面：默认跟随系统语言，也可手动切换。

## 使用

开启鼠标前，请授予悬浮窗与无障碍服务权限。主界面提供鼠标指针开关、隐藏/显示、权限设置、“其他设置”和“说明”。在“其他设置”中可调整灵敏度、指针大小、外观、语言及快捷键。

默认情况下，音量加键 + 菜单键打开设置，音量减键 + 菜单键开启固定滑动。可在“其他设置 → 快捷键设置”中修改这些操作的触发方式。

## 兼容性

支持 Android 4.4（API 19）至 Android 15（API 35）。
