# TV Mouse

[简体中文](./README.md)　|　[English](./README.en.md)

Control the mouse pointer on Android TV with a remote and operate other apps like using a mouse.

## Features

- Floating mouse pointer: move with the D-pad, click with OK, and hold OK to perform a long press.
- Pointer sensitivity and size controls in Other Settings.
- Main screen: pointer enable/disable, hide/show, overlay permission, accessibility settings, Other Settings, and Help.
- Custom shortcuts: configure shortcuts for opening settings, enabling Fixed Scroll, hiding/showing the pointer, and disabling Fixed Scroll under **Other Settings → Shortcut Settings**.
- Button combinations: use one or more buttons, up to three; the configured action triggers when the combination is pressed.
- Long-press shortcuts: choose any remote button and configure its hold duration. The minimum is 1000 ms, with no upper limit.
- Fixed Scroll: Volume Down + Menu enables it by default; holding Back for 3 seconds disables it by default. Both can be customized.
- Custom pointer appearances: import 128 × 128 pixel PNG or JPG images, set an appearance as the pointer, rename it, or delete it. Normal and Fixed Scroll modes can share an appearance.
- Chinese and English interfaces, following the system language by default with manual switching available.

## Usage

Grant overlay and accessibility permissions before enabling the mouse. The main screen provides pointer controls, permission shortcuts, Other Settings, and Help. Other Settings includes sensitivity, pointer size, appearance, language, and shortcut configuration.

By default, press Volume Up + Menu to open settings and Volume Down + Menu to enable Fixed Scroll. Change these actions under **Other Settings → Shortcut Settings**.

## Compatibility

Android 4.4 (API 19) through Android 15 (API 35).
