# 电视鼠标

[简体中文](./README.md)　|　[English](./README.en.md)

在 Android TV 上用遥控器控制鼠标指针，在其他应用中也能像鼠标一样操作。

## 功能

- 悬浮鼠标指针：方向键移动，确定键单击，按住确定键执行长按。
- 鼠标灵敏度与指针大小：可在“其他设置”中调整。
- 精简主界面：主界面仅提供开启/关闭鼠标指针、隐藏/显示鼠标指针和“其他设置”入口。
- 固定滑动：按音量减键 + 菜单键开启；开启后只有长按返回键 3 秒才能关闭。
- 快捷键设置：在“其他设置”中为打开设置和开启固定滑动配置单键、多键组合或指定按键的长按时长。
- 指针悬停反馈：悬停在可点击链接或交互控件上时显示悬停高亮，并切换为伸出食指的 Link Select 手形指针。
- 自定义指针外观：导入 128 × 128 像素的 PNG 或 JPG 图片，可设为鼠标指针、修改名称或删除；普通指针、固定滑动指针与 Link Select 指针可分别选择共用或独立外观。
- 中英文界面：默认跟随系统语言，也可手动切换。

## 使用

开启鼠标前，请授予悬浮窗与无障碍服务权限。主界面提供鼠标开启/关闭、指针隐藏/显示与“其他设置”三个入口。进入“其他设置”可调整灵敏度、指针大小、外观、语言及相关权限。

快捷键可在“其他设置 → 快捷键设置”中自定义，支持单键、多键组合和长按指定按键。固定滑动开启后，仍需长按返回键 3 秒关闭。若无障碍服务异常导致遥控器失去响应，可先在系统无障碍设置中关闭“电视鼠标”服务，再重新开启。


## 兼容性

支持 Android 4.4（API 19）至 Android 15（API 35）。
